# Background Color Changer

Simple React app to change background color. Built with React + Vite + Tailwind CSS.

🚀 **Live Link:** https://anjali-chauhan-rajput.github.io/bgChanger01/
💻 **GitHub:** https://github.com/Anjali-Chauhan-Rajput/bgChanger01

## Features
- Change background color on click
- Responsive design
- Built with React useState Hook

## Tech Stack
- React
- Vite
- Tailwind CSS
- GitHub Pages
